# 介護どうぶつ診断（仮）

介護職向けの動物タイプ診断 Web アプリです。40問に答えると、動物のキャラで自分のリーダータイプがわかり、半年分の成長ステップが手に入ります。

- 正式な心理検査ではありません。自分を知るきっかけ・話し合いの材料として使ってください
- 人事評価には使いません
- 回答と結果はこの端末の中だけに保存され、どこにも送られません

## 動かし方

Node.js 22.12 以上と pnpm が必要です。

```bash
pnpm install
pnpm dev
```

表示された `http://localhost:5173/` をブラウザで開きます。

## 文章を直すとき

質問・説明文・成長ステップは `data/` の JSON にあります。コードを触らずに直せます。直したら `pnpm test` で文章のルール（1文50字以内など）を確かめてください。
