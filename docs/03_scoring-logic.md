# 判定のしくみ

実装：`src/scoring.ts`／テスト：`tests/scoring.test.ts`／設計書 §5-3

## 1. 軸ごとの点数（右側寄り度）

1. 答えを 1〜5 の数にする（「そう思わない」＝1 … 「そう思う」＝5）
2. 質問の `direction` が `right` ならそのまま、`left` なら `6 − 答え` にする（右側に寄るほど大きい数）
3. その軸の質問だけで平均し、`(平均 − 1) ÷ 4 × 100` で **右側寄り度（0〜100）** にする
   - 実装では誤差を避けるため `(合計 − 問題数) × 100 ÷ (4 × 問題数)` で計算する
4. **50 以上なら右側**、50 未満なら左側
5. 画面の％は寄っている側の値を四捨五入（右側寄り度 28.125 → 左側 71.875 → 「72％」）
6. 右側寄り度が `axes.json` の `balanceRange`（40〜60、両端を含む）なら **バランス型**
   - バランス型でも、動物と型の判定には 4. の側を使う

1軸8問・5段階なので、右側寄り度は **3.125 きざみ**。40 と 60 ちょうどは出ない（50 は出る）。

| 8問の答え | 合計 | 右側寄り度 | 側 | 表示 | バランス型 |

| 5,5,5,5,5,5,5,5 | 40 | 100 | 右 | 100％ | × |
| 1,1,1,1,1,1,1,1 | 8 | 0 | 左 | 100％ | × |
| 1,1,1,2,3,3,3,3 | 17 | 28.125 | 左 | 72％ | × |
| 2,2,2,2,3,3,3,3 | 20 | 37.5 | 左 | 63％ | × |

## 2. 動物・型・グループ

- 各軸の側に対応する `axes.json` の `left.code`／`right.code` を並べる
- **動物**：A〜D のコード（例 `LTFK`）→ `animals.json` の `code`
- **型**：E のコード（`D` どっしり型／`M` こまやか型）
- **コード全体**：`LTFK-D`
- **グループ**：動物コードの先頭2文字（A と B）→ `animals.json` の `groups[].axes`

## 3. 結果を出さない条件

- 1問でも未回答があれば結果を出さない（`IncompleteAnswersError`）

## 4. 例

- 全問「どちらともいえない」→ 全軸 50（右側・バランス型）→ `SHFN-M`（カワウソ・こまやか型）
